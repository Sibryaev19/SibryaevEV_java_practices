## 🎯 Общее описание
Разработан RESTful веб-сервис для управления каталогом книг и авторов с поддержкой форматов JSON и XML, XSLT-преобразованием для браузерного отображения и полноценным веб-интерфейсом.

## ✅ Выполненные задания

### 📝 **Задание 1: Выбор Spring REST**
**Выбор:** Spring REST Framework  
**Аргументация:**
1. **Spring Boot** обеспечивает быстрый старт и автоконфигурацию
2. **Интеграция с Spring Data JPA** для удобной работы с БД
3. **Автоматическая сериализация** XML/JSON через Jackson
4. **Аннотационный подход** (`@RestController`, `@GetMapping`) более лаконичен
5. **Широкая экосистема** и отличная документация
6. **Встроенная поддержка** Content Negotiation

### 📚 **Задание 2: REST API для приложения "Каталог книг"**
- **Сущности:** Авторы (Author) и Книги (Book)
- **CRUD операции:** Создание, чтение, обновление, удаление
- **Связи:** Один ко многим (Автор → Книги)
- **Полный REST API** с HTTP методами GET, POST, PUT, DELETE

### 🔄 **Задание 3: API с поддержкой XML и JSON**
✅ **Поддерживаемые форматы:**
- **Выходные данные:** `application/json`, `application/xml`
- **Входные данные:** `application/json`, `application/xml`
- **Content Negotiation:** На основе заголовка `Accept`

✅ **Реализовано через:**
- `@RestController` для автоматической сериализации
- Jackson с аннотациями `@JsonManagedReference`/`@JsonBackReference`
- Конфигурация в `XmlXsltConfig.java`

### 🎨 **Задание 4: XSL-преобразование**
✅ **XSLT файл:** `transform.xsl` в статической части веб-слоя  
✅ **Функциональность:**
- Преобразование XML → HTML для браузерного отображения
- Отображение данных объектов (авторов и книг)
- **Навигация между сущностями:**
  - Список авторов → Список книг
  - API информация → Детали сущностей
  - Веб-интерфейс → REST API

### 🏷️ **Задание 5: XSLT тег в XML-откликах**
✅ **Реализация:** Фильтр `XsltHeaderFilter.java`  
✅ **Функциональность:**
- Автоматически добавляет `<?xml-stylesheet type="text/xsl" href="/transform.xsl"?>`
- В начало всех XML-ответов REST API
- **Особенность:** В Spring Boot 4.0.0 используется `application/xhtml+xml`

### ⚡ **Задание 6: Полная работоспособность**
✅ **Всё работает вместе:**
- Веб-интерфейс (HTML/JavaScript)
- REST API (JSON/XML)
- XSLT преобразование
- База данных PostgreSQL
- Фильтр для XSLT-тегов

## 🛠 Технологический стек

### **Backend:**
- **Java 17**
- **Spring Boot 4.0.0** (новейшая версия)
- **Spring Data JPA** (работа с БД)
- **Spring MVC** (веб-слой)
- **Jackson** (сериализация JSON/XML)

### **База данных:**
- **PostgreSQL 15+**
- **Hibernate** (JPA провайдер)

### **Frontend:**
- **HTML5/CSS3** (веб-интерфейс)
- **JavaScript (ES6)** (динамические операции)
- **XSLT 1.0** (преобразование XML→HTML)
